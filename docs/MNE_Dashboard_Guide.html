01 · Orientation

What MNE Does

Macro Narrative Engine (MNE) is an evidence-driven market intelligence system. It helps you understand the current market environment, the dominant narratives driving attention, the catalysts ahead, and — just as importantly — how much you should trust the evidence behind all of it.

Every dashboard run follows the same pipeline. Headlines and data are collected, sorted into narrative themes, measured for strength and change over time, and then layered against real market and calendar context. The result is a single page that tells you what the market conversation currently looks like, and how solid the ground under that read actually is.

Market evidence
Headlines, prices, and scheduled events collected and deduplicated
↓
Narrative classification
Evidence sorted into themes (energy, ai, inflation…) and narrative groups
↓
Narrative dynamics
Persistence, acceleration, pulse, and leadership rotation over time
↓
Market & catalyst context
Price action, breadth, positioning, and the calendar layered on top
↓
Dashboard intelligence
A single reviewed page, plus a stated confidence level for the read
MNE is

An evidence-driven market intelligence system that helps you understand the current market environment, dominant narratives, catalysts, positioning, and the quality of the evidence behind the read.

MNE is not

A stock-picking service, a prediction engine, a trade-signal generator, a guaranteed forecasting tool, or financial advice. MNE helps you understand the environment you are making decisions in — it does not make the decision for you.

03 · Orientation

How to Use MNE in 60 Seconds

A practical first pass through the dashboard, in the order you should actually do it.

  1. Confirm the Data Quality banner. Is the evidence base Strong, Usable, Limited, or Thin? This tells you how much weight to put on everything below it.
  2. Read the Market Environment. One label (e.g. "Energy Shock," "Clean Risk-On") tells you the backdrop MNE is reading right now.
  3. Identify the dominant narrative. Check the Narrative Leadership section for the #1 card and its share of total narrative attention.
  4. Check whether it's strengthening or fading. Look at Pulse, Acceleration, and the rotation badge (Stable, Losing, Challenging, and so on) on that same card.
  5. Review upcoming catalysts. The Catalyst Environment card tells you how dense the next two weeks of scheduled events are.
  6. Compare the narrative with market behavior. Regime Alignment and the narrative/market relationship label tell you whether price action agrees with the story.
  7. Open Research Workspace when you need more. Click "Investigate narrative" on any leadership card to see the underlying evidence.
How to read this guide

Sections 04–17 explain each dashboard element in the order you encounter it on the page. Section 18 covers the Research Workspace, Section 19 covers Historical Replay. If you only read one more section right now, read Section 20 — what MNE can and cannot tell you.

04 · Run Context

Run Context & Data Quality

Before you read anything else, the dashboard tells you how much evidence it had to work with, and how current that evidence is.

Which run am I looking at?

MNE writes a new result file every time it runs. The dashboard defaults to the latest meaningful run — the newest run that actually produced narrative signal — rather than simply the newest file on disk.

Selected run
You explicitly chose a run from the Run dropdown. MNE shows exactly that file, with no substitution.
Latest meaningful run
The default. MNE walks backward from the newest file until it finds one with real theme or group scores, skipping any run that produced no narrative signal. If it had to skip forward, a banner tells you so: "Latest run had no narrative signal; showing latest meaningful run."
Latest run (Admin only)
The Admin view shows the literal newest file regardless of content, so an operator can see empty or failed runs the public dashboard hides.

Reading the Trust Summary

The banner at the top states one of five evidence-base labels, a confidence level, a plain-language reason, and a row of supporting facts.

StateWhat it means
Strong evidence baseAmple accepted evidence, healthy provider network, good coverage.
Usable evidence baseEnough evidence to read with normal confidence, without being exceptional.
Limited evidence baseMeaningful constraints exist in the evidence network — read with more caution.
Thin evidence baseVery little accepted evidence, or the dashboard had to fall back to an older meaningful run.
Data unavailableNo run data or diagnostics could be loaded at all.

The fact row spells out the inputs behind that label: Accepted evidence (how many evidence items passed acceptance checks this run), Providers (distinct upstream sources), Evidence network (a composite network-health read), Source confidence (how well sources fetched and contributed this run), and Coverage (how broadly that evidence was spread across narratives).

What this does not mean

Data confidence describes the evidence base — how much was collected, how fresh it is, how many independent sources agree it exists — not confidence that the market will move in a particular direction. A "Strong evidence base" run can still describe a highly uncertain market; a "Thin evidence base" run can still be directionally correct. They are answering different questions.

05 · Primary Read

Market Environment

Market Environment is the hero headline at the top of the dashboard. It answers one question:

"What kind of market backdrop is currently present?"

MNE checks a fixed, ordered set of conditions — narrative signals (macro stress, AI strength, energy dominance), how concentrated attention is, and two market moves (QQQ and VIX) — and returns the first label that matches:

StateRoughly means
Energy ShockEnergy and inflation scores are both elevated alongside high or rising macro stress.
Risk-OffVolatility sharply higher, Nasdaq down, and Macro Pressure is the dominant narrative.
Fragile Risk-OnStocks up, but volatility is also sharply higher and macro stress is high — a shaky rally.
AI MomentumAI / Tech Growth dominates, AI narrative score is strong, and Nasdaq is strongly higher.
Clean Risk-OnNasdaq strongly higher, volatility flat or down, AI leading, macro stress low.
Macro StressMacro stress is high alongside Macro Pressure leadership or rising volatility.
Narrative RotationNo narrative group clearly dominates; the top two groups are close in score.
Low-Conviction ChopNasdaq and volatility both flat, and attention isn't concentrated. Also the fallback state.

Each state also carries a confidence (High / Moderate / Low, based on how many corroborating conditions fired) and a reason — a fixed, human-written sentence explaining the match.

Figure 5.1 — The hero read from a live run: state "Broad Macro Read" is the Operating Mode's plain-language framing (see Section 09); the underlying Market Environment label for this run was Energy Shock, visible in the metric grid.

Worked example

On the run captured for this guide, the Market Environment card read Energy Shock, with the reason: "Energy and inflation scores are elevated while macro stress remains high." That single label told the user, before reading anything else, that the backdrop was commodity- and inflation-driven rather than a clean risk-on or risk-off tape.

Do not interpret it as

A forecast of what markets will do next, or an instruction to buy or sell energy-sensitive assets. It is a classification of present conditions, not a projection of future ones.

06 · Primary Read

Narrative Leadership

This section answers: which story is currently dominating market attention, and by how much?

Theme, group, and dominance — how they relate

Theme
A single keyword-scored topic, e.g. energy, ai, inflation, recession, rates
↓ rolled up into one of four fixed groups
Narrative Group
AI / Tech Growth · Macro Pressure · Energy / Commodities · Geopolitical Risk
↓ the group with the highest score this run
Dominant Narrative Group
Ranked #1 on the Narrative Leadership cards
Theme Score
A keyword-weighted count of matching headlines for one theme. Stronger keyword matches ("strong" = 3, "medium" = 2, "weak" = 1 point) are summed across non-overlapping matches.
Group Score
The sum of its constituent themes' scores. Energy / Commodities, for example, sums the energy, oil, and commodities theme scores.
Dominant Narrative Share
The leading theme's count divided by total mentions across all themes — how much of the total conversation the top story occupies.
Concentration Gap
The point gap between the top theme and the runner-up. A large gap means a clear leader; a small gap means a close contest.
Narrative Concentration
The general idea that Dominant Share and Concentration Gap together describe — is attention spread across many stories, or piled onto one?
Leadership label
Each ranked card also carries a plain-language tag: Dominant Narrative (#1), Challenging Leadership (a close #2), or Secondary Narrative (further back).

Do not interpret it as

A prediction that the dominant narrative will keep leading. It is a same-run ranking of existing narrative-group scores, nothing more.

07 · Primary Read

Pulse

What it is
A per-narrative-group score (the "strength index") that measures how strongly a narrative is currently pulling attention, weighted mostly by its share of total narrative-group score and how many consecutive runs it has held the lead.
Use it to answer
"How much force is behind this narrative right now — is it a passing mention or the center of gravity?"
Inputs
Group's share of total narrative-group score (weighted most heavily), leadership persistence in consecutive runs, the group's raw current score, and its acceleration state (Accelerating / Stable / Cooling).
What it does not mean
Pulse is deliberately kept separate from acceleration, crowding, and market direction. A high Pulse does not mean the narrative is accelerating, and it says nothing about whether price is confirming it — check Acceleration (Section 10) and Regime (Section 08) separately.
Compare with
Narrative Leadership rank (Section 06), Acceleration (Section 10), and Regime Alignment (Section 08) to see whether narrative strength, trend, and market confirmation all agree.

The five Pulse states

Dormant
0–14
Emerging
15–29
Building
30–49
Strong
50–69
Dominant

Each Pulse reading also carries its own confidence (High / Medium / Low), based on how much share and persistence back up the state — a "Strong" Pulse backed by 30%+ share and a multi-run streak is High confidence; a "Strong" reading with thin support is Low confidence.

How it differs from a market signal

Pulse measures narrative attention and leadership persistence — not price, not volume, not options flow. A Dominant Pulse describes how much the story is dominating coverage, not how the related assets are trading. For that, look at Regime Alignment and the narrative/market relationship state (Sections 08 and 13).

08 · Primary Read

Regime

On the dashboard, "Regime" refers to Regime Alignment — a single 0–100 score measuring how well price and market action are confirming the current dominant narrative.

Market Environment

Classifies the current backdrop (Energy Shock, Risk-Off, Clean Risk-On…) from price moves and narrative signals.

Regime (Regime Alignment)

Scores, 0–100, how well narrative leadership is being confirmed by price, breadth, positioning, and catalysts.

Operating Mode

A display-only interpretation lens (Macro or Nasdaq) that turns the same underlying data into a plain-language "read" sentence. It does not change any score.

How the score moves

Regime Alignment starts at a neutral base of 50 and is adjusted by five inputs: the narrative/market relationship state (confirmation adds, divergence or exhaustion subtracts), breadth confirmation, market environment, positioning, and Nasdaq-specific price/volatility context. The result is clamped to 0–100.

ScoreState
80–100High Alignment
60–79Moderate Alignment
40–59Mixed / Low Alignment
20–39Conflicted Environment
0–19Highly Conflicted Environment
Figure 8.1 — Regime Alignment History from a live run — the score's day-over-day path, ending at 60.0 (Moderate Alignment).
Do not interpret it as

A trend-strength or volatility-regime indicator in the traditional technical-analysis sense. It specifically measures narrative-to-market agreement, nothing else.

09 · Primary Read

Operating Mode

Operating Mode is an interpretation lens, not a scoring input. Two modes are currently implemented:

Macro

The default mode. Produces a fixed-format "Broad Macro Read" state and a Moderate-confidence sentence naming the dominant group, market state, and breadth state.

Nasdaq

A richer, Nasdaq-specific read built from QQQ, NVDA, VIX, and DXY moves, macro stress, AI dominance, catalyst positioning, breadth, and Regime Alignment. States include Nasdaq Macro Pressure, Nasdaq Pre-Catalyst Chop, Nasdaq Risk-On Confirmation, Nasdaq Divergence, and Nasdaq Mixed Conditions.

What changing the mode affects

Mode changes only the generated headline sentence and its confidence label — it does not change Pulse, Regime Alignment, group scores, theme scores, or any other underlying calculation. Both modes read the same evidence; they just narrate it differently. An unrecognized mode value silently falls back to Macro.

10 · Primary Read

Narrative Dynamics

A narrative's score tells you where it stands right now. Dynamics tell you where it's headed.

Persistence
How many consecutive runs a theme or group has held the dominant position. Shown as a run-streak count feeding both Pulse and the Recent Memory panel in Research Workspace.
Acceleration
Compares the most recent score change to the prior one. States: Accelerating (the move is speeding up), Cooling (slowing down), Stable, or Insufficient history with fewer than three runs on record.
Momentum
A related but separate trend classifier used in reporting and Narrative Memory: Building, Fading, Cooling, Re-accelerating, Flat, or Stable, based on the last two run-over-run deltas.
Crowding
How concentrated and persistent attention on the dominant narrative has become — High / Moderate / Low, from dominant share, streak length, and acceleration. The engine's own note is explicit: this measures narrative attention crowding, not actual market positioning.

Narrative Memory states

In the Research Workspace, a "Recent Memory" panel classifies a narrative's recent behavior into one label: Dominant, Persistent, Building, Fading, Recurring, Re-accelerating, Dormant, Emerging, or Absent, alongside plain-language context like appearances, dominance count, streak length, and score/share deltas.

Reading dynamics together — three examples

High score, fading

A group leads on raw score but Acceleration reads Cooling and Momentum reads Fading — the lead is inherited from past runs, not being reinforced today.

Lower score, accelerating

A #3 group with a modest score but Accelerating momentum can be more informative than a flat #1 — it signals where attention is moving next.

Dominant but losing share

A group can remain #1 by score while its Dominant Share shrinks run over run — leadership intact, but the margin narrowing.

A note on "Entrenched" and "Decelerating"

These two labels are not currently produced anywhere in MNE's dynamics or memory engine. If you've seen them used informally, treat the closest current equivalents as Persistent / Dominant (for "entrenched") and Cooling (for "decelerating").

11 · Primary Read

Narrative Brief

The Narrative Brief translates the run's numbers into a short, plain-language explanation — a headline, a summary, and a handful of key points, each traceable back to the exact fields that produced it.

Figure 11.1 — A live Narrative Brief, with its "Data Completeness" badge and key points.
Headline & summary
Generated from a library of pre-written templates, each gated behind a required-evidence check. A template is only used if every field it needs is actually present in the run.
Key points
One line per section (Dominant Story, Why It Changed, Market Agreement, Attention, Overall Assessment), each naming the exact modules that supported it.
Data Completeness
The label shown on the badge is the brief's internal confidence field (High / Medium / Low), relabeled for the reader. It drops when required inputs for a section are missing, or when more than one generation template conflicted.
When evidence is limited
Each section has a fallback template ("Dominant narrative data is unavailable for this run.") that fires automatically rather than fabricating a read. A style guide also blocks hype language — words like "guaranteed," "certain," or "will" are rejected at the template level, before a brief is ever generated.
Read this as

An explanation of the current narrative structure, not as a forecast. Every sentence in the brief is grounded in a specific, logged field from this run — it is describing what already happened in the evidence, not projecting what happens next.

12 · Primary Read

Catalyst Environment

The Catalyst Environment answers: how much scheduled market-moving news is coming, and how well-verified is that calendar?

Density and state

MNE counts upcoming red (high-impact) and orange (medium-impact) events over the next 14 days. Density score = (red events × 2) + orange events.

Density scoreState
0Quiet
1Light
2–3Moderate
4–5Elevated
6+Heavy

What counts as red vs. orange

High-impact (red) events currently include CPI, PPI, the Employment Situation (the monthly jobs report), FOMC decisions and press conferences, GDP, and Personal Income and Outlays (which carries the PCE price index). Medium-impact (orange) events include JOLTS, the Employment Cost Index, Import/Export Price Indexes, FOMC Minutes, International Trade, and the EIA's weekly petroleum and natural-gas reports.

Importance is not direction

A CPI print being flagged "high-impact" says nothing about whether it will be bullish or bearish. The red/orange label is purely about expected attention and volatility, never about direction. Nothing in the catalyst engine assigns bullish or bearish meaning to any event.

Verified quiet vs. calendar unavailable

A density score of 0 alone is not enough for MNE to claim "nothing is coming." It only labels the calendar Quiet when the automatic macro-calendar refresh is healthy and current. If that refresh was partial, stale, missing, or unparseable, MNE reports Calendar Unavailable or Calendar Stale instead of Quiet — and lowers catalyst confidence — so a failed check is never mistaken for a genuinely clear calendar.

Verified QuietCalendar Unavailable / Stale
Macro calendar refreshed successfully, and no red/orange events found.The refresh itself failed, was partial, or every stored event date is in the past — MNE cannot confirm there's nothing coming.
Figure 12.1 — Live Catalysts card showing state Heavy with a Calendar Notice — the calendar found events, but the refresh itself was only partial, so MNE flags that upcoming coverage may be incomplete even while reporting a real state.

Company earnings catalysts are sourced automatically for a fixed watchlist of ten large-cap names (NVDA, AAPL, MSFT, GOOGL, META, AMZN, AMD, TSM, AVGO, TSLA); anything outside that list must be added manually to the catalyst calendar.

13 · Primary Read

Market Confirmation & Divergence

This is the narrative/market relationship classifier — it compares what the narrative is saying against what price is actually doing.

StateWhat it means
Narrative ConfirmationThe AI / Tech Growth narrative is stable or accelerating, and QQQ and NVDA are both up while volatility stays controlled — price is validating the story.
Narrative DivergenceThe AI / Tech Growth narrative is still strong by score, but QQQ or NVDA is down — the story isn't being confirmed by price.
Narrative ExhaustionAttention crowding is High, the same group has led for 5+ runs, share is 50%+, but price is now weakening — the narrative may be overextended.
Narrative RotationThe dominant group changed from the prior run, or the leader is cooling while another group accelerates.
Neutral / MixedNo clear pattern, or required inputs were unavailable.
A scope note

The Confirmation and Divergence states are currently only defined for the AI / Tech Growth group. Other dominant groups (Macro Pressure, Energy / Commodities, Geopolitical Risk) will show Rotation or Neutral / Mixed instead — they don't yet have their own confirmation logic.

Examples

  • AI narrative strengthens, and QQQ and NVDA both confirm with volatility contained → Narrative Confirmation.
  • Energy headlines accelerate, but energy-sensitive assets don't respond → this shows up as Rotation or Neutral / Mixed, since the confirmation logic only tracks AI / Tech Growth directly.
  • Macro stress rises while defensive positioning firms up → reflected through Regime Alignment's market-environment and positioning inputs, not this classifier directly.
Do not interpret it as

A trade signal. "Confirmation" means price and narrative currently agree — it is not an instruction to buy, and "Divergence" is not an instruction to sell.

14 · Primary Read

Breadth

Breadth checks whether index-level moves are broadly shared or concentrated in a handful of large names, using SPY, RSP (equal-weight S&P 500), QQQE (equal-weight Nasdaq-100), and IWM (small caps) alongside QQQ, NVDA, and VIX.

Broad participation

QQQ, SPY, and RSP all rising together, volatility flat or down — strength shared across cap-weighted, equal-weight, and small-cap names.

Narrow participation

QQQ and NVDA up while equal-weight and small-cap proxies lag or fall — the index move is a small number of names doing the work.

StateMeaning
Strong Breadth ConfirmationBroad-based strength across cap-weighted, equal-weight, and small-cap participation.
Broad Risk-OffBroad-based selling across the same participation set, with volatility rising.
Narrow LeadershipHeadline strength concentrated in QQQ/NVDA while broader participation lags.
Weak BreadthHeadline index holding up while underlying participation is deteriorating.
Neutral BreadthNo clear broad confirmation or deterioration — the fallback state.
What breadth does not prove

Breadth can support or weaken confidence in a narrative read, but it does not by itself prove a move is real or fake — it is one more piece of corroborating context, best read alongside Regime Alignment and the narrative/market relationship state.

Positioning

On the current dashboard, "Positioning Environment" is a calendar-driven classifier — it describes how close the market is to a high-impact scheduled event, not trader positioning, options skew, or futures data.

Heavy Event PositioningCatalyst density score is 6 or higher.
Elevated Positioning ActivityCatalyst density score is 4 or higher.
Pre-Catalyst PositioningA high-impact event is scheduled tomorrow.

Figure 15.1 — In this live run, Positioning read Unknown — "No catalyst environment data available." — a reminder that this classifier depends entirely on the catalyst calendar being present in the shape it expects.
What this does not mean

MNE does not currently compute trader positioning, options-market crowding, one-sided futures positioning, or unwind risk from market data — those concepts are not implemented in the codebase. What's labeled "Positioning" here is contextual and calendar-based: it tells you how close you are to a scheduled catalyst, not how crowded a trade is. Do not use it as a timing signal for entries or exits. The separate "narrative crowding" concept (Section 10) measures attention concentration, not market positioning, either.

16 · Context Mapping

Market Expression Map

MNE maintains a static map from each theme to the assets typically associated with it — primary names, secondary names, and offsets (hedges or inversely-related instruments).

Not currently shown on the dashboard

This mapping is computed on every run and saved into the run's data, but it is not rendered anywhere in the current dashboard interface. It exists in the underlying data and in text/CLI reports, and it can be cited as supporting context inside a Narrative Brief, but there is no dashboard panel for it today. If you see asset tickers referenced in brief text, this map is the likely source.

When it is surfaced (in reports or future dashboard views), each entry is explicitly labeled: "These assets are narrative-expression proxies and not trade recommendations."

If this is ever added to the dashboard

The Market Expression Map identifies assets connected to a narrative. It does not tell the user to buy or sell them.

17 · Supporting Detail

Trends

The Narrative Leadership History table tracks which group led each day, its dominant share, and the gap to the runner-up — the run-over-run story behind the leadership cards.

Figure 17.1 — Ten trading days of daily leadership history from a live run. Notice the leadership change from AI / Tech Growth to Energy / Commodities around 07/07, and back-and-forth with Macro Pressure through mid-July.

One run per day, not one row per run

MNE can be run more than once on the same day. To keep this history meaningful, the daily trend views (this table, and the CLI trend reports) collapse each calendar day down to its single most recent run before charting it — so re-running MNE five times on a Tuesday does not inflate Tuesday's weight in the trend line to five data points. This day-collapsing logic is separate from the "Recent Memory" panel in Research Workspace, which instead looks at the last N runs directly, regardless of how many fell on the same day.

How to read the Gap column

Gap is the point difference between the day's leader and the runner-up. A widening gap over successive days means the leading narrative is pulling away; a narrowing gap means the field is tightening — worth cross-checking against the rotation badge on the live leadership card.

Headline-level evidence, stated honestly

The Evidence Reader panel is explicit about its own limits. Every item includes the line: "This interpretation is based on the persisted headline and evidence metadata. Full article text is not available in MNE." and "This is not a complete article summary." MNE tells you directly when its knowledge of a story stops at the headline.

Coverage in this view (Minimal / Limited / Moderate / Broad / Extensive) describes how broad the supporting evidence is for one narrative — how many items, sources, and providers back it — and is explicitly not a judgment of narrative quality. Source Summary lists each contributing source with its health and freshness state.

19 · Going Deeper (Admin)

Historical Replay

Historical Replay reconstructs what MNE would have shown on a past date, using only evidence that MNE had actually stored at or before that moment. It is an admin-only, read-only feature.

Evidence published
on or before the cutoff
→ included
CUTOFF
Evidence published
after the cutoff
→ excluded

Why replay results may be thin

Two separate limits apply. First, replay can only draw on evidence MNE actually persisted at the time — if live collection wasn't running yet for a given date, there is nothing to replay. Second, an optional Historical Backfill can add older evidence from outside sources, but today that backfill covers exactly one source: Federal Reserve / FOMC public communications. It is explicitly labeled partial coverage, not a full market-news reconstruction.

How replay differs from current intelligence

Live dashboardHistorical Replay
EvidenceCurrent, ongoing collectionPersisted evidence only, up to a chosen cutoff
Live fetchingYesNever
AccessPublic dashboardAdmin only, read only
Use caseWhat's happening nowWhat MNE could have known on a past date

Historical Comparison takes two completed replay artifacts and shows what changed between them — dominant theme/group shifts, score deltas, and evidence-base differences — without generating any new evidence or scores.

Read with caution when evidence is thin

Historical Research views carry their own warnings when source coverage is limited, and state directly: "Historical coverage may be incomplete if MNE had limited stored evidence for this date." Older replays should be trusted less by default, not more.

20 · Scope

What MNE Can & Cannot Tell You

MNE can help with

  • Identifying which narrative is dominating market attention right now
  • Understanding how much and how reliable the underlying evidence is
  • Recognizing when narrative leadership is changing or rotating
  • Seeing which high-impact events are coming up
  • Comparing a narrative's strength against how price is actually behaving
  • Structuring how you prepare for a session, methodically and repeatably

MNE cannot guarantee

  • Market direction, on any timeframe
  • Exact price targets
  • Profitable trades
  • The outcome of any scheduled event
  • Timing precision for entries or exits
  • Complete historical evidence coverage
  • Perfect or continuous source availability
The one sentence to remember

MNE helps a user understand the environment in which they are making decisions. It does not make the decision for them.

21 · Practice

Suggested Daily Workflow

Before market open

  • Check run freshness and the Data Quality banner — confirm you're not looking at a stale or thin run.
  • Read the Market Environment and identify the dominant narrative.
  • Review upcoming catalysts and note anything red (high-impact) in the next day or two.
  • Note the confirmation/divergence state — is price already agreeing with the story, or not yet?
  • Ask yourself: what specific evidence, if it appeared today, would invalidate this read?

During the session

  • Use MNE as context for interpreting what you're seeing — not as an entry trigger by itself.
  • Watch whether price action is confirming or rejecting the environment MNE described this morning.
  • Resist forcing a trade just because a narrative is dominant — dominance is a description of attention, not permission to act.

After the session

  • Compare what changed against the "What Changed Since Last Run" card.
  • Review acceleration and persistence — is the story building, cooling, or unchanged?
  • If something surprised you, open Research Workspace and read the actual supporting evidence, not just the score.

Complete Glossary

Every term used on the dashboard, defined in one place. Where a state applies specific numeric thresholds, see the relevant numbered section for detail.

Accepted Evidence
An evidence item that passed acceptance checks this run (not a duplicate, not stale, has a parseable timestamp). Counted on the Trust Summary banner.
Acceleration
Whether a narrative's score change is speeding up (Accelerating), slowing (Cooling), or flat (Stable), based on the last three runs. §10
Breadth
Whether index-level strength or weakness is shared broadly across cap-weighted, equal-weight, and small-cap proxies, or concentrated in a few names. §14
Catalyst
A scheduled, market-relevant event — a macro data release, a Fed decision, an earnings report — tagged as high-impact (red) or medium-impact (orange). §12
Catalyst Density
A weighted count of upcoming red and orange catalysts within a 14-day lookahead window. §12
Catalyst Environment
The dashboard card combining catalyst density, state, and calendar-coverage confidence. §12
Concentration Gap
The score gap between the top theme and its closest rival. Larger = clearer leader. §06
Confidence
Appears throughout the dashboard with different scopes each time — evidence-base confidence, catalyst confidence, Pulse confidence, brief confidence. Always read it next to the label it's attached to, not on its own.
Confirmation
"Narrative Confirmation" — price action (currently tracked for AI / Tech Growth) agreeing with a strengthening narrative. §13
Coverage
How broadly a narrative's supporting evidence spans across items, sources, and providers: Minimal, Limited, Moderate, Broad, or Extensive. Not a quality judgment. §18
Crowding
How concentrated and persistent narrative attention has become (High/Moderate/Low) — explicitly not a measure of market positioning. §10, §15
Data Completeness
The user-facing label for a Narrative Brief's internal confidence score (High/Medium/Low). §11
Divergence
"Narrative Divergence" — a strong or accelerating narrative (currently tracked for AI / Tech Growth) whose related assets are falling instead of confirming it. §13
Dominant Narrative
The single theme with the highest score this run. §06
Dominant Narrative Group
The narrative group (of four fixed groups) with the highest summed score this run. §06
Dominant Narrative Share
The dominant theme's mention count divided by total mentions across all themes. §06
Energy Dominance
A narrative-strength signal for the energy theme: HIGH, ELEVATED, or LOW, based on share and concentration. Feeds Market Environment.
Entrenched
Not currently produced by MNE's dynamics or memory engine. The closest current states are Persistent and Dominant. §10
Evidence Funnel
The count of items fetched vs. accepted (fresh) vs. rejected (stale, duplicate, or unknown-timestamp) each run.
Evidence Network
The Trust Summary fact label for the composite Network Confidence / Network Health read. §04
Evidence Reader
The Research Workspace panel that gives a headline-level summary of one evidence item, with explicit "what MNE knows / does not know" sections. §18
Exhaustion
"Narrative Exhaustion" — high, persistent attention crowding on a dominant narrative even as price begins weakening. §13
Feed Health
Per-source fetch outcome this run: Healthy, Partial, Empty, Offline, Redirected, Parse Error, Rate Limited, Blocked, or Unknown.
Freshness
Whether evidence or a source's latest item arrived within its configured recency threshold: Fresh, Stale, Unknown, or (source-level) Quiet.
Group Score
The sum of a narrative group's constituent theme scores. §06
Historical Replay
An admin-only reconstruction of what MNE would have shown on a past date, using only evidence persisted at or before a chosen cutoff. §19
Latest Meaningful Run
The newest result file that actually produced narrative signal — the dashboard's default, skipping empty or failed newer runs. §04
Macro Stress
A composite signal (HIGH/ELEVATED/MODERATE/LOW) built from energy, rates, inflation, and recession theme intensity. Feeds Market Environment and Regime.
Market Environment
The classified current market backdrop (Energy Shock, Risk-Off, Clean Risk-On, etc.). §05
Market Expression
A static per-theme map of associated primary, secondary, and offset tickers. Computed, but not currently shown on the dashboard. §16
Momentum
A trend classifier (Building/Fading/Cooling/Re-accelerating/Flat/Stable) used in reporting and Narrative Memory. §10
Narrative
A recurring market story tracked at either theme level (e.g. "energy") or group level (e.g. "Energy / Commodities"). §06
Narrative Brief
The generated plain-language explanation of the current dominant narrative and its supporting evidence. §11
Narrative Concentration
How much of total narrative attention is piled onto the leading story, vs. spread across several. §06
Narrative Group
One of four fixed roll-ups: AI / Tech Growth, Macro Pressure, Energy / Commodities, Geopolitical Risk. §06
Narrative Leadership
The ranked view of narrative groups by score, with rotation and Pulse context. §06
Narrative Persistence
Consecutive runs a theme or group has held the dominant position. §10
Network Confidence
A composite trust signal (HIGH/MODERATE/LOW/VERY_LOW/UNKNOWN) built from network health, source confidence, source reliability, and coverage together. §04
Network Health
Feed-infrastructure status by provider and category: Healthy, Partial, Degraded, or Critical. §04
Operating Mode
The display lens (Macro or Nasdaq) used to narrate the same underlying data. Does not change scoring. §09

Not a single fixed state — used loosely for two distinct things: a partial macro-calendar refresh (§12), and Minimal-level narrative evidence coverage, labeled "Thin" on the Trust Summary (§04).
Positioning
A calendar-proximity classifier — not trader positioning, options data, or unwind risk. §15
Pulse
A per-group strength index (Dormant/Emerging/Building/Strong/Dominant), weighted mostly by share and leadership persistence. §07
Regime
Regime Alignment — a 0–100 score measuring how well price action confirms the dominant narrative. §08
Rotation
Two distinct uses: "Narrative Rotation" (a narrative/market relationship state, §13) and a leadership card's rotation badge (Dominant/Holding/Challenged/Challenging/Emerging/Losing/Stable, describing rank stability, §06).
Source Confidence
A single-run, whole-network read of fetch success, contribution, and freshness ratios: High/Moderate/Low/Unknown. §04
Source Reliability
A per-source, multi-run behavioral track record: Stable/Watch/Repeated Failure/Quarantine Recommended/Unknown. §04
Theme
The most granular narrative unit — e.g. energy, ai, inflation, recession, rates. §06
Theme Score
A keyword-weighted count of matching headlines for one theme. §06

A Trust Summary state: very little accepted evidence this run, or a forced fallback to an older meaningful run. §04

The Data Quality banner at the top of the dashboard, stating evidence-base state, confidence, and supporting facts. §04

A "Quiet" catalyst state backed by a successful, current macro-calendar refresh — distinct from a calendar that's simply unavailable. §12
