# Installation

## Windows

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Run

Run engine:

```powershell
python main.py
```

Run dashboard:

```powershell
python dashboard.py
```

Open:

```text
http://localhost:8000
```

## macOS

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
